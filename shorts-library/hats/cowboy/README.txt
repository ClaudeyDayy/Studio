COWBOY HAT (made 2026-11-09 for Max, "Infinite chess" v4)
- hat_max_front.png / hat_max_back.png : 600 x 1000 transparent layers on the same grid as the cast pictures
  (drawn on top of the head layer). Brown felt, pinched crown, scratched leather band with stitching,
  brass buckle (front only), paper size tag "7 1/2" on a string.
- hat_max_mask.png : black = erase this part of the head picture (hair above the brim) before drawing the hat.
- hat.html : the drawing code. Open hat.html?v=front | back | mask in Chrome to redraw or change colours.
- Fits Max's head. For Arian or Ava, make a fitted copy first (their heads have different shapes).
Use in a cast sheet: add  "hat": "cowboy"  to a scene; pick-assets.mjs copies hats/cowboy/hat_<character>_*.png.
